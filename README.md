Read all attached files completely before implementation. Treat RR_2027_Lovable_Master_Prompt_v2.md as the authoritative build specification and the JSON/CSV as the data sources.

Build the entire Rajasthan Royals 2027 War Room in one implementation pass. Do not stop after the homepage, do not return a plan instead of implementation, and do not omit any specified page or interaction to save tokens.

Implement all pages, navigation, squad builder, player cards, rankings, auction strategy, responsive layouts, animations and transitions. Preserve the exact supplied player data and rankings. Do not invent statistics, injury updates, auction prices or player availability.

Prioritise a complete working website over excessive decorative effects. At the end, run the build checks, fix errors, and report exactly what is implemented and what remains incomplete.
